# Iris Basic Classification

This is a basic Data Science project that demonstrates loading data, performing simple exploratory data analysis (EDA), generating a visualization, and training a Random Forest Classifier to classify the Iris dataset.

## Setup

1. Install Python 3.
2. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the main script to see the output:
```bash
python main.py
```

This will print the model's accuracy and a classification report. It will also generate a `pairplot.png` in the `outputs/` directory.
